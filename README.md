# Anders Edh VVS & Kyla AB – hemsida

Statisk webbplats (HTML/CSS/JS, inga byggsteg) för Anders Edh VVS & Kyla AB, IVT-partner i Hudiksvall.

- `index.html` – allt innehåll
- `styles.css` – design
- `script.js` – meny, animationer och kontaktformulär (öppnar e-postprogrammet)
- `assets/img/` – optimerade bilder (JPG + WebP)

**Innan publicering:** ange företagets riktiga e-postadress i `script.js` (`EMAIL`).

Kan publiceras direkt på t.ex. GitHub Pages, Netlify eller valfritt webbhotell – ladda bara upp filerna.
